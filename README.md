# kicad-cruncher has moved

Active development of `kicad-cruncher` moved to the
[`wavenumber-eng/kicad_monkey`](https://github.com/wavenumber-eng/kicad_monkey)
repository under
[`packages/kicad_cruncher`](https://github.com/wavenumber-eng/kicad_monkey/tree/main/packages/kicad_cruncher).

The move became effective on August 9, 2026, with the first monorepo release,
`kicad-cruncher` 2026.8.9.

The PyPI distribution and command names are unchanged:

```text
pip install kicad-cruncher
kicad-cruncher --help
kcr --help
```

Please report issues and propose changes in
[`wavenumber-eng/kicad_monkey`](https://github.com/wavenumber-eng/kicad_monkey/issues).

This archived repository preserves the standalone project's Git history, tags,
and releases for historical reference.
