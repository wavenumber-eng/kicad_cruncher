## Cached Design-Review PCB SVG Implementation

Implemented the accepted `design/dr` cheap window:

- `_render_pcb_review_svgs()` now creates one command-scoped `PcbSvgCompositionRenderCache(pcb)` per design-review bundle.
- Each copper-layer SVG is rendered through `_cached_pcb_review_svg_text()`, which calls `render_cache.root_svg(pcb, [layer, Edge.Cuts])` and then feeds the result through the existing `_style_pcb_review_svg()` path.
- The existing artifact writing, manifest fields, included layers, review theme styling, draw-order pass, and drill/slot record counting are unchanged.
- No daemon-wide, plugin-wide, mutable-board, or process-wide cache was added.
