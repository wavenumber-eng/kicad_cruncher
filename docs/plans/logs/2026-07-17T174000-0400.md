# Log: api-guidance-doc-updates

## API Guidance Documentation Updates

Updated durable guidance for the accepted `design/dr` optimization:

- `README.md` now states that design review still materializes full design JSON and netlist artifacts, while PCB review SVG generation reuses command-scoped board render state. It also notes that gains mainly scale with copper-layer count and that design JSON can still dominate low-layer boards.
- `docs/design/cli/design.html` now describes PCB review SVGs as produced from cached `kicad-monkey` board IR plus an all-layer bounding box, filtered per copper layer and `Edge.Cuts`.
- The design command doc now explicitly states cache lifetime is one design-review bundle only, and that the cache preserves enriched metadata, `viewBox`, width, height, coordinate framing, review styling output, and drill/slot record counts.
- `docs/adrs/ADR-0002-cli-install-and-dependency-discipline.md` now records the controlled runtime floor as `kicad-monkey>=2026.7.17`.

Release notes are intentionally deferred to the release-candidate-prep step because the package version has not been bumped and no release authorization has been granted.
